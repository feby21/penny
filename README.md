# Penny – clickable demo

Plain HTML, CSS and JavaScript. No frameworks, build tools, backend or API keys.

## Run it

Open `index.html` in a browser (double-click works). All data is kept in `localStorage`;
**Reset demo** at the bottom of Home reloads the seed data and restarts onboarding.

## 2-minute demo script

1. Onboarding: enter a name, or tap "Skip setup and use the demo profile".
2. Home → **Scan Nectar card at Sainsbury's** → 12 items sync (2 land on "2 days left").
3. Inventory: the new items carry a purple **Nectar** tag and an "est." expiry.
4. Header → **+1 day** → an "expires in 2 days" alert appears (toast + bell badge).
5. **+1 day** twice more → an "expires today" alert appears.
6. Meal Plans → a 3-day plan that uses the expiring items; try **Regenerate** and **Mark cooked**.
7. Community → like a recipe, open it and post a comment.
8. Recipes → **Upload recipe**, leave it Public → it is first in Community (Newest).
